# 🎓 Student Registration Form

A modern, responsive, and visually appealing **Student Registration Form** built with pure HTML and CSS. It features a sleek glassmorphic card design, smooth animations, customized form elements, and gradient color accents.

---

## 🚀 Features

* **Modern UI/UX:** Designed with a vibrant dark background gradient, soft drop shadows, and a frosted-glass form container (`backdrop-filter`).
* **Responsive Layout:** Automatically scales across different screen sizes, ensuring usability on mobile devices, tablets, and desktops.
* **Interactive Elements:** 
  * Smooth focus effects with custom borders and glow animations on input fields.
  * Custom styled dropdown selectors, radio buttons, and a dashed file upload zone.
  * A glossy hover-animated submit button.
* **Comprehensive Fields:** Captures essential student details including Full Name, Father's Name, Roll Number, Gender, Class selection, Course selection, Photo upload, and an address/message box.

---

## 🛠️ Built With

* **HTML5:** Semantic markup structure.
* **CSS3:** Custom styles, Flexbox layout, CSS Keyframe animations, and gradients.
* **Google Fonts:** Utilizes the `Poppins` typography font family.
